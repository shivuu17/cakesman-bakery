## 🚀 Your Deployment Journey (45 minutes)

### Step 1: GitHub Setup (5 min)
```
Create public repo at https://github.com/new
Name: cakesman-bakery
```
✅ Get your repo URL

---

### Step 2: Push Code (1 min)
```powershell
cd d:\Cakesman-Bakery
git remote add origin [YOUR_REPO_URL]
git branch -M main
git push -u origin main
```
✅ Code is on GitHub

---

### Step 3: Setup Database (5 min)
```
Go to https://cloud.mongodb.com
Create free cluster
Create database user
Copy connection string
```
✅ Database ready

---

### Step 4: Deploy Backend (10 min)
```
Go to https://railway.app
New Project → Deploy from GitHub
Select cakesman-bakery repo
Root Directory: backend
Add environment variables:
  - MONGODB_URI
  - JWT_SECRET
  - PORT=5001
```
✅ Backend deployed (e.g., https://xxx.railway.app)

---

### Step 5: Update Frontend Code (5 min)
**3 files to update:**

1. `frontend/src/utils/api.js`
   - Add: `process.env.REACT_APP_API_URL`

2. `frontend/src/context/SocketContext.jsx`
   - Use env variable for backend URL

3. `backend/server.js`
   - Configure CORS for Vercel domain

Then: `git push origin main`

✅ Code updated

---

### Step 6: Deploy Frontend (5 min)
```
Go to https://vercel.com
New Project → Import GitHub repo
Select cakesman-bakery
Root Directory: frontend
Add env var: REACT_APP_API_URL
Deploy
```
✅ Frontend deployed (e.g., https://cakesman-bakery.vercel.app)

---

### Step 7: Test! (10 min)
```
Visit: https://cakesman-bakery.vercel.app
Test all features
Check console (F12) for errors
Share with friends!
```
✅ Live on the internet!

## 🆘 If You Get Stuck

1. **Check the error message** - It usually tells you what's wrong
2. **Check the logs:**
   - Vercel Dashboard → Deployments → Logs
   - Railway Dashboard → Logs
   - Browser Console (F12)
3. **Read the troubleshooting section** in DEPLOYMENT_GUIDE.md
4. **Common issues:**
   - Wrong root directory → Check Vercel/Railway settings
   - API not responding → Check backend URL in env vars
   - Database connection error → Check MongoDB URI
   - CORS errors → Check backend CORS configuration
